# Raiz & Forma

Site institucional e catálogo digital da Raiz & Forma, marca de cocares têxteis decorativos feitos à mão.

## Funcionalidades

- Conteúdo em português, francês e inglês
- Catálogo visual responsivo
- Encomendas e pedidos personalizados pelo WhatsApp
- Informação sobre entregas internacionais

## Desenvolvimento local

Abra `index.html` num navegador ou sirva a pasta com qualquer servidor HTTP estático.
